File format

The first row is a header. Every other row has a type and the scheme it belongs to. Define a scheme with a SCHEME row first, then add its CRITERION, DOCUMENT and STEP rows. A row that starts with # is a comment.

typecolumns used
SCHEMEscheme (English name), name_ta, description, description_ta, benefit_type, benefit_amount, category
CRITERIONscheme, parameter (age, income, family_size, education_level, location, occupation, category, marital_status, gender), operator (BETWEEN, LESS_THAN_OR_EQUAL, GREATER_THAN_OR_EQUAL, EQUALS, IN_LIST), min_value, max_value, allowed_values (comma separated), mandatory (true or false)
DOCUMENTscheme, document_name, requirement_type (MANDATORY or OPTIONAL)
STEPscheme, step_number, step_text, portal_link (optional, must start with http:// or https://)

Every scheme needs at least one CRITERION row. Use BETWEEN, LESS_THAN_OR_EQUAL and GREATER_THAN_OR_EQUAL only for age, income and family_size. Put values that contain commas inside double quotes.
